# Curated visual baseline

This is the shell-facing subset of the 2026-07-28 UI audit: 73 PNGs selected
from 155 source captures. Files are copied snapshots, not symlinks, so this
branch remains self-contained.

Included:

- web authentication and first-load states;
- platform shell, menus, work surfaces, and responsive states;
- administration and moderation;
- community/leaderboard states;
- app entry, app detail, and the App/Dev boundary;
- representative development workspaces, project views, chat, issue/proposal
  states, and app-management surfaces.

Excluded as out of scope or redundant:

- Flutter-native authentication, wallet/node, benchmark, permissions, and
  diagnostics;
- the visual interiors of hosted emoji child apps;
- repeated child-app development landings and redundant deep-workspace captures.

The screenshots are evidence of user-visible jobs and states. They are not
pixel-perfect targets and should not override current component, token,
accessibility, or data-boundary authority.
