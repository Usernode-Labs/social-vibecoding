# Planning reviews

These reviews are preserved because they changed the work, not simply because
they existed.

1. `01-react-commitment-and-spike-review.md` made the React commitment,
   performance budget, coexistence scenario, and token authority explicit.
2. `02-decision-and-agent-benchmark-review.md` required a named decision and a
   reproducible agent benchmark rather than a qualitative scorecard.
3. `03-accessibility-and-colour-research.md` supplied the contrast and inclusive
   design research used to treat accessibility as a contract.
4. `04-engineering-heuristics.md` provided general inspection lenses. Only the
   relevant authority, observability, reversibility, and failure-signalling
   heuristics were applied.
5. `05-plan-reconciliation-review.md` reconciled competing process models and
   made T4 enforcement and Storybook portability precise.

The source text is retained verbatim below a short provenance heading in each
file so future agents can distinguish review evidence from current repository
instructions.
